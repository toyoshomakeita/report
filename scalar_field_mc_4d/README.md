# 4次元実スカラー場の格子モンテカルロシミュレーション

## 概要

4次元ユークリッド空間上の実スカラー場 \(\phi(x)\) を格子場理論の手法でシミュレーションし、
相関関数 \(G(r) = \langle \phi(0)\phi(r) \rangle\) を測定して質量 \(m\) を推定する。

## 物理的背景

### ウィック回転

ミンコフスキー空間の経路積分 \(Z = \int \mathcal{D}\phi\, e^{iS\_M[\phi]}\) は重みが複素数で振動するため
モンテカルロ法が使えない。時間座標を虚数化 \(t \to -i\tau\)（ウィック回転）することでユークリッド作用

\[ S\_E = \int d^4x \left[ \frac{1}{2} \sum\_{\mu=1}^4 (\partial\_\mu \phi)^2 + \frac{1}{2} m^2 \phi^2 \right] \]

が得られ、重み \(e^{-S\_E}\) は実数となり確率的サンプリングが可能になる。

### 格子上の局所作用

格子間隔 \(a=1\) として差分化すると、1点 \(x\_0\) の局所作用は

\[ S\_{\text{local}}(x\_0) = 4 \phi(x\_0)^2 - \phi(x\_0) \sum\_{n=1}^8 \phi(x\_n) + \frac{1}{2} m^2 \phi(x\_0)^2 \]

となる。係数4は次元数 \(d=4\)、隣接点数8は4次元×2（正負方向）に由来する。

### 相関関数の理論形

4次元自由スカラー場の伝播関数はBessel関数を用いて

\[ G(r) = \frac{1}{(2\pi)^2} \left( \frac{m}{r} \right) K\_1(mr) \]

と書け、遠方で \(G(r) \sim \frac{1}{r^2} e^{-mr}\) の漸近形を持つ。
これを利用して \(\ln(G(r) \cdot r^2)\) の傾きから質量を推定する。

### コード構造

* **`ScalarField4D(L, m, delta)`**: 4次元配列 `phi[L][L][L][L]` を保持
  + `get_local_action(x, y, z, t)`: 指定点の局所作用を計算（周期境界条件）
  + `metropolis_sweep()`: 全 \(L^4\) 点を1スイープ、採択率を返す
  + `calculate_correlation(max_r)`: 4軸方向に平均した相関関数を計算
* **`main.py`**: \(L=6\)、\(m=1.0\)、熱化200sweep、測定400sweep（interval=5）で実行し、\(\ln(G(r) \cdot r^2)\) の線形フィットから有効質量を推定

## 結果と考察

* **入力質量**: \(m = 1.0\)
* **推定有効質量**: \(m\_{\text{eff}} \approx 0.37 \sim 0.5\)（理論値から乖離）
* **乖離の原因**:
  1. **有限サイズ効果**: \(L=6\)（\(6^4 = 1296\)点）は非常に小さく、周期境界条件の影響で相関が底上げされる
  2. **格子効果**: 連続空間の回転対称性が粗い格子上では破れる
  3. **フィッティング不安定性**: 最大距離 \(r\_{\max}=3\) と点が少なく統計誤差が大きい
* **改善策**: \(L \ge 16\) への拡大、スイープ数の増加
